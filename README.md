# 心智圖編輯器

國小老師上課用的心智圖工具。網址：https://andice0107.github.io/mindmap-editor/

## 功能
- 多張畫布分頁、自動存檔（存在瀏覽器）、存成／開啟 .json 檔（也能開舊版 CodePen 存的檔）
- 電腦滑鼠、iPad 觸控（拖曳、兩指縮放）都能用
- 自由連結線：可畫在任何地方，端點靠近方塊自動接上、拖開就分離，可拉彎、加文字
- 淺色／深色／溫暖三種主題、一鍵套色、多種教學範本
- 方塊可加表情符號、圖片、注音（破音字可手動改）、挖空
- 列印 A4／A3、挖空學習單、上課投影模式（一支一支或一層一層出現）
- 匯入／匯出 Markdown、PNG、SVG、Mermaid

注音字典 `zhuyin-dict.json` 來源：教育部《重編國語辭典修訂本》。
